# FarmTech

FarmTech is an interactive smart-farm operations concept built with Next.js and React Three Fiber. It combines a navigable 3D farm scene with planning, insights, calendar, connector, and voice-control interfaces.

## Highlights

- Interactive 3D farm rendered with Three.js
- Zone-based navigation and animated camera transitions
- Operations dashboards for planning and farm insights
- Responsive interface animations with Framer Motion
- Mock farm telemetry for exploring the experience locally

The current repository is a front-end prototype. Data shown in the interface is illustrative and is not connected to production farm equipment.

## Run locally

Requirements: Node.js 20 or newer and npm.

```bash
git clone https://github.com/Faiyazs07/FarmTech.git
cd FarmTech
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Useful commands

```bash
npm run dev
npm run lint
npm run build
npm start
```

## Technology

Next.js 16, React 19, TypeScript, Tailwind CSS, React Three Fiber, Drei, Three.js, Framer Motion, GSAP, and Zustand.
